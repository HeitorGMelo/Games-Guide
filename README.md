🎮 Games Guide 🎮

O Games Guide é um projeto desenvolvido em caráter de estudo, com o objetivo de praticar front-end e aprender a construir interfaces interativas e dinâmicas. 
A ideia é criar um guia de jogos moderno e visual, onde o usuário possa explorar títulos, ver informações detalhadas, assistir trailers e salvar favoritos.
O projeto foi pensado como uma base evolutiva — começando simples, mas planejado para receber novas funcionalidades com o tempo.

📦 Tecnologias utilizadas
-HTML5
-CSS3
-JavaScript (ES6)
-Swiper.js

🔮 Futuras Atualizações
O Games Guide começou como um teste prático de CSS, voltado para estudar posicionamento, responsividade e efeitos visuais.
A ideia agora é transformar esse experimento em algo mais completo, aplicando o que for aprendido ao longo do processo
-Área de favoritos aprimorada, com categorias e persistência de dados.
-Página de detalhes do jogo, com sinopse, notas e recomendações relacionadas.
-Adicionar tema claro/escuro e customização de cores.
-Transições e animações mais suaves com CSS e JS.
-Sistema de login simples, permitindo salvar preferências do usuário.
-Versão mobile otimizada e futura conversão em PWA
-Ranking de jogos mais populares e seção “Descubra novos títulos”.
